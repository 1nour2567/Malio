Malio — 设计概要

AI 私人电台 DJ · Agent 架构 · 深色 Matrix 主题

一、Agent 架构（五阶段循环）

1. Perception接收用户消息 + 环境上下文（时间/天气/日程）+ 用户偏好历史
2. Routing显式命令直执行 / 自然语言转入推理
3. ReasoningPlan-and-Solve 三段式 + ReAct 交替循环
4. Tool UseTool Registry：音乐搜索 / 播放控制 / 音乐库 / TTS / 天气
5. FeedbackDJ 口吻回复 + 更新播放列表 + WebSocket 推送前端

二、视觉系统

主题深色 OLED (#000000)，JetBrains Mono + IBM Plex Sans
代码流底层Canvas 粒子系统，256 粒子池；左右代码行作为发射源；播放器绕流 + 下方 20px 缓冲区减速虚化消失
绕流算法径向推离 + 切向速度；碰撞检测用卡片外扩矩形
动态参数5-10s 采样环境（心情/天气/时间/音乐能量），5s 平滑插值过渡到粒子属性
Agent 日志层磨砂玻璃底条，底部上浮 16px，停留 3s 自动渐隐；拟人化前缀
播放器控件白色/浅灰中性基调，进度条用环境色；卡片带微光外发光

三、布局 — 全屏播放器

顶部栏（48px）☰ 菜单 · Malio 品牌 · 🔍 搜索 · 💬 聊天 · ⚙️ 设置
主区域全屏 Canvas 代码流背景 + 居中播放器卡片（代码流在此绕行）
侧边面板聊天 / 搜索从右侧滑出，40% 宽度 + 半透明遮罩
Agent 日志播放器卡片下方，磨砂玻璃悬浮
移动端 (<768px)左右代码缩为顶部细条；聊天/搜索全屏弹出；Canvas aria-hidden

四、交互

桌面端图标按钮 + 快捷键提示。空格播放/暂停，←→ 切歌，/ 聊天输入，Ctrl+K 搜索
移动端边缘滑动手势。卡片上左右滑动切歌，粒子跟随偏转
门槛PWA 可安装到桌面，Service Worker 离线缓存
