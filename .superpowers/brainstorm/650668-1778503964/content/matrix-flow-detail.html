动态参数映射

环境参数 影响的视觉属性 效果
心情：开心 流速 ↑ / 颜色暖绿 字符轻快下落，暖绿色
心情：低落 流速 ↓ / 颜色蓝紫 字符缓慢飘落，冷色调
天气：晴天 密度低 / 透明度高 稀疏的字符，透出背景
天气：雨 密度高 / 速度略快 密集的字符，模拟雨感
时间：夜间 亮度降低 / 颜色偏暗 字符变暗，不刺眼
音乐：激烈 振幅大 / 字符跳跃 字符有节奏地波动
音乐：舒缓 振幅小 / 字符平滑 字符安静匀速下落

技术实现：Canvas + 粒子系统

  • 用 HTML5 Canvas 绘制，不阻塞主界面渲染
  • 每个字符是一个粒子：{x, y, char, speed, opacity, color}
  • 检测播放器卡片位置 → 粒子进入碰撞区 → 计算绕流路径
  • 绕流后粒子 opacity 衰减到 0，在卡片下方消失
  • 每秒更新一次环境参数（心情/天气），平滑插值过渡
